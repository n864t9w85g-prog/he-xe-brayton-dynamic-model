# 方案 B 散热器来源约束候选族设计

**日期：** 2026-08-29

**状态：** 方案 A 书面规格已批准，实施计划编写中

**验证对象：** 论文方案 B 的 NaK 回路与辐射散热器参数可识别性

**实施区域：** 仅 `tests/` 与 `tmp/`

**正式模型：** 本规格不加载、不仿真、不修改 `final_steady_24a.slx`

## 1. 目标

建立一个来源约束的离线候选族，回答以下问题：

1. 论文直接公开量、引用文献技术分支与当前项目参数之间分别是什么关系；
2. 在不使用论文曲线终点反算并回填参数的前提下，哪些散热器参数组合满足基本物理、质量和能量约束；
3. 哪些量能够由公开资料唯一确定，哪些只能确定组合量、区间或条件关系；
4. 当前 `A=1113 m²`、`h=9.755 W/(m²·K)`、`M=5744 kg`、`epsilon=0.9`、`Cp=900 J/(kg·K)`和`m_NaK=6.95 kg/s`是否落在来源约束的可行域内；
5. 若可行域非空，输出可供下一轮临时模型实验使用的候选分支；若不可唯一识别，明确报告不可识别性，不强行给出一个“最佳参数点”。

本任务的产物是**可识别性地图、候选分支和淘汰证据**，不是正式模型修复。

## 3. 核心设计原则

### 3.1 不把待验证输出当作独立输入

表 5.2 端点、图 5.18(d)终点与启动曲线是验证对象。可以用它们形成约束、残差和条件反推关系，但所有反推量必须标记为“条件识别量”，不得再作为独立来源输入证明同一曲线。

### 3.2 优先识别组合量

公开信息不足时，不强行拆分以下组合：

- `epsilon*A_rad`或分布式辐射积分对应的有效辐射能力；
- `h_i*A_i`、`h_r*A_rad`或总传热能力`UA`；
- `M_rad*Cp_wall`或有效壁面热容`C_wall`；
- `m_dot_NaK*DeltaH_NaK`。

只有独立来源足以拆分时，才分别报告面积、系数、质量和比热。

### 3.3 来源分支与数学敏感性分离

- **来源分支：** [147]表 I 的16个面密度分支；每个分支保留材料、翅片密度、单/双面和成熟度标签。
- **论文约束：** 方案B质量账、表5.2端点/功率、式(2.63)/(2.64)/(5.15)/(5.16)。
- **项目对照：** 当前6项活动参数，只用于判断是否可行。
- **数学敏感性：** 对未公开的`epsilon`、面积比、`UA`和`C_wall`首先给符号关系、单调性和物理边界；未经独立来源或新的人工批准，不把任意离散采样点称为物理候选。

## 5. 计算层级

### 5.1 层级0：文件、哈希与来源合同

输入文件固定为：

- 徐驰论文固定哈希副本；
- NASA/TM-2007-215003固定哈希副本；
- NASA/TM-2008-215420固定哈希副本；
- `data/provenance/radiator_source/juhasz/`中的来源矩阵；
- 既有NaK物性来源审计结果；
- 方案B质量账审计结果；
- 图5.18(d)数字化数据仅作为后级观察目标。

任一原始哈希变化时，计算停止，不静默接受新版本。

### 5.2 层级1：质量可行域

已确认严格约束为：

```text
M_rad + M_TAC <= 4650 kg
M_TAC >= 0
M_rad = kappa*A_rad
```

因此每个`kappa`分支先得到不依赖TAC具体质量的面积上界：

```text
A_rad <= 4650/kappa
```

该上界只用于淘汰，不反称为正确面积。若后续可靠识别图4.10中的TAC或散热器质量，可增加更紧的约束，但不得覆盖本轮原始记录。

### 5.3 层级2：NaK稳态能量约束

按已溯源的NaK物性分别计算：

```text
DeltaH = integral(cp_NaK(T), T_low, T_high)
Q_NaK = m_dot_NaK*DeltaH
m_dot_conditional = Q_CHX/DeltaH
```

输出必须区分：

- `6.95 kg/s`：项目对照边界；
- 由`1622 kW`和当前物性得到的流量：条件反推；
- 作者实际流量：未知。

不得通过修改比热或流量使三元组强制闭合。若不同可溯源物性给出不同条件流量，报告区间与来源，不挑最接近6.95的一项作为“正确”。

### 5.4 层级3：辐射能力与面积关系

使用[120]的分布式方法和论文式(2.63)建立两级计算：

1. **理想上界：** 壁温等于局部NaK温度、没有内部温差；给出在指定冷源温度下的最小`epsilon*A_rad`需求。
2. **有限换热关系：** 保留`h_r`或`UA`及面积比为显式变量，求解流体—壁面温差和辐射积分关系。

理想上界不是实际设计。若某个质量分支连理想上界都无法同时满足质量账和排热需求，则可直接淘汰；通过理想上界的分支只表示“未被这一必要条件排除”。

冷源温度若论文未给出，不采用当前项目`225 K`作为论文事实。计算应优先输出关于`T_sink`的关系；任何数值示例必须把`T_sink`标记为敏感性输入。

### 5.5 层级4：动态时间尺度关系

图5.18(d)约120–150 s稳定是论文观察目标。候选族先识别：

```text
C_wall = M_rad*Cp_wall
tau_effective ~ C_wall/(local radiative slope + fluid-wall exchange slope)
```

本层只形成有效热容/时间常数组合关系：

- 不从一条曲线同时反解`M_rad`和`Cp_wall`；
- 不把图像反演出的`C_wall`称为材料数据；
- 不使用同一曲线反演参数后再把同一曲线计为独立验证通过；
- 图像数字化误差和时间轴分辨率必须进入不确定性记录。

### 5.6 层级5：当前项目参数审判

把当前活动参数组作为一个单独的`legacy_current`记录，依次检查：

1. 方案B质量账；
2. NaK能量闭合；
3. 面积来源独立性；
4. 换热系数来源独立性；
5. 动态热容来源独立性；
6. 是否使用同一论文输出完成参数反算和验证。

预计`M=5744 kg`会在质量层直接失败。其余参数即使数学上可用，也不能因终点吻合而通过来源门。

## 6. 淘汰与保留规则

### 6.1 硬淘汰

出现以下任一条件即淘汰该候选分支：

- 违反`M_rad+M_TAC<=4650 kg`；
- 需要`epsilon<=0`或`epsilon>1`；
- 需要负面积、负质量、负热容或负的耗散型传热系数；
- 不能在能量守恒下排出1622 kW；
- 依赖把当前终点反算值冒充独立来源；
- 来源材料/结构与所用`kappa`分支不一致；
- 需要额外控制器、反馈、目标回注或曲线补丁。

### 6.2 条件保留

满足必要条件但仍含作者未公开量时，标记为`conditionally_feasible`，并列出仍需的独立输入。不得标为“论文模型已恢复”。

### 6.3 来源优先级

若多个分支均可行，排序只按以下顺序：

1. 直接论文依据；
2. 已试验的引用技术分支；
3. 已制造但未试验分支；
4. 先进材料推演分支；
5. 纯数学敏感性点。

曲线误差不得越过上述来源优先级自动选中某一分支。
