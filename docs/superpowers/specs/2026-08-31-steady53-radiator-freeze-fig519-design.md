## 2. 备选路线与选择理由

### 路线 A1：散热器证据固化后直接进入图 5.19（采用）

优点：

- 图 5.19 直接检验反应堆、透平、压气机和发电功率，和后续 §5.4 的功率—转速耦合关系最近；
- 当前“论文有明显瞬态、模型几乎为直线”的差异足够大，适合先定位初始化和输出定义问题；
- 能把“终值接近”和“瞬态复现”拆成两个独立验收维度；
- 可先复用现有 14000 s 保存数据，不立即增加仿真消耗。

风险：论文未公开完整初始状态，最终可能得到非唯一初态族。该结果必须如实记录，不能用自动拟合选出一个“最像”的包。

### 路线 A2：先攻图 5.18(c) 冷却器

优点是单部件边界较清晰，已有六组固定输入诊断和独立稳态消元。缺点是 NaK 流量和能量口径仍未唯一闭合，且完成冷却器并不能直接解释图 5.19 的反应堆与 TAC 功率瞬态。本轮不采用，但保留为图 5.19 上游温度链需要时的支撑任务。

### 路线 A3：暂停实验，继续寻找作者原始模型

优点是若找到原始模型，可直接解决缺失初态和参数身份。缺点是仓库和现有 Git 历史已经没有该实现，外部搜索结果不可预期。本轮不作为阻塞主线；若后续获得作者源码或补充材料，再作为更高等级证据接入。

## 6. P1：初始状态、输入边界和数据流盘点

### 6.1 基线复用

先复用已保存的原 14000 s 数据及其前 500 s 段，不重新运行同一基线。只有缺少必要直接信号且无法从原 MAT/CSV恢复时，才允许在新的唯一 `tmp/` 目录运行一次只增加只读记录的 500 s 基线。

### 6.2 状态清单

通过 MATLAB/Simulink 官方 API 只读列出：

- 全部连续状态、离散状态和对应物理部件；
- 每个状态的保存初值、来源表达式和数据类型；
- 初值来自块参数、模型工作区、基础工作区、MAT、外部操作点还是计算脚本；
- 图 5.19 四个输出从状态和边界输入到功率计算的完整路径；
- t=0 的固定边界、时变边界和首个采样后的边界；
- 当前求解器、采样时间和任何 StopTime 依赖采样行为。

SLX 解包仅用于只读交叉检查。任何探索副本修改必须通过官方 API 完成。

### 6.3 初始残差

在不改变模型的前提下计算或记录：

- 四个功率在 t=0 的值；
- 关键储热和反应堆状态的初始导数；
- 功率平衡、换热器能量和转子过剩功率残差；
- 当前状态距离自身 500 s／14000 s 终态的差异。

本阶段的完成条件是回答：哪些状态或输入使当前模型从近稳态开始，以及哪条直接数据流导致每条功率曲线近乎平直。不能仅以“初值不对”作为笼统结论。

## 7. P2：单假设探索副本实验

### 7.1 实验顺序

实验只允许按以下顺序逐项推进：

1. **输出定义检查：** 不改变状态，只比较直接功率、净轴功率、论文 `0.98` 派生量和历史 `0.96527` 派生量；这一步不仿真或只复用已有输出。
2. **初始化因果检查：** 根据 P1 的实际状态依赖图，一次只改变一个物理上自洽的初始状态合同；其余参数、方程、边界和求解器保持不变。
3. **边界施加时序检查：** 只有初始化不能解释论文的起始方向时，才检查稳态输入是在 t=0 阶跃施加、从某个初值过渡还是全程固定；不得同时改变初态和时序。
4. **结构检查：** 若有来源的初态和时序仍不能产生四条曲线的符号、峰谷次序和时间尺度，回到对应部件方程和状态定义；不继续增加自由参数。

### 7.2 初态候选的允许来源

允许：

- 论文白纸黑字给出的初值；
- 当前模型状态定义和方程要求的物理一致初值；
- 明确标为诊断上下界的状态族，用于证伪而非选优。

禁止：

- 从四条目标曲线反解一整套状态后再用同一曲线宣称验证；
- 自动优化初值、时间常数、效率、传热系数或功率系数；
- 为降低 RMSE 同时改变多个物理部件；
- 平移时间轴、平滑、截去不利的早期段或使用人工曲线补丁。

### 7.3 副本和运行规则

- 每个候选从耐久稳态基线重新独立复制，不从前一候选串改；
- 所有结构或参数变化通过官方 MATLAB/Simulink API 执行；
- 每个候选保存补丁清单、源/候选 SHA256、变化前后参数、模型重开审计和运行日志；
- 先运行最短能够证伪的时段，只有通过数值完整性和因果门才运行 500 s；
- 图 5.19 本身是 0–500 s 目标，不因为稳态项目曾要求 14000 s 就自动把每个诊断都推进到 14000 s；
- 不修改正式模型，不加载外部初始操作点到正式交付路径。

## 8. 比较指标与停止门

### 8.1 分层指标

每条曲线分别报告：

- 原始未处理轨迹；
- 起点误差；
- 峰/谷方向、幅值和出现时间；
- 500 s 终值误差；
- 约 230 s 后是否保持在自身终值带内；
- 数字化点 RMSE、最大绝对误差和分时段平方误差贡献；
- 曲线一阶方向变化和四条功率之间的因果次序。

读图余量只描述论文扫描分辨率，不自动成为正式验收标准。数字化完成后，若需要把曲线误差设为硬通过门，必须单独形成明确阈值并经人工批准。

### 8.2 物理与数值门

候选必须同时满足：

- `SimulationOutput.ErrorMessage` 为空并到达指定终止时间；
- 所有记录状态和输出有限；
- 没有物性域、查表域或物理断言失败；
- 功率单位和机械轴功率／电功率定义不混用；
- 能量和功率残差按活动方程独立复算；
- 正式受保护文件哈希保持不变；
- 没有新增控制器、状态回注、拟合补丁或未授权物理机制。

### 8.3 停止门

出现以下任一情况即停止该方向：

1. 候选只改善终值，却没有恢复论文峰谷方向或时间次序；
2. 需要同时改变两个以上未有来源的物理变量才能继续；
3. 多个不同初态包都能同样解释图 5.19，作者实现不可唯一识别；
4. 需要更改 `0.98`、加入控制器或用输出反馈来压曲线；
5. 数值失败发生在比论文差异更上游的物性或查表域；
6. 实验将重复已有 A1、散热器初值或压力闭合结果而没有新增可证伪问题。

停止不等于项目失败。必须保存证据，明确标记根因已定位、根因候选、不可识别或外部来源缺失，再选择下一个独立目标。
