# 压缩机查表模块修正设计

> **已废止：** 本文件记录的是早期 `3.0-paper-shape` Gaussian 诊断代理方案，不能用于
> 论文复现。论文图 5.3 是压缩机 Simulink 模型框图，图 5.4 是封装子系统，并未给出
> 性能线族。正式方案见
> `docs/superpowers/specs/2026-08-17-paper54-dynamic-reproduction-design.md`；正式候选数据
> 必须来自 NASA TM X-2269 数字化实测线和有界相似定律预测。

## 目标

修正 `final_steady_24a/TAC/Compressor` 中压比和等熵效率两张二维查表面，使其呈现徐驰论文图 5.3 所示的压缩机特性线族：各转速线的压比均为平滑的先升后降曲线，效率均为平滑单峰拱形曲线。

本次只替换查表数据与其元数据，不改变现有 Simulink 模块接口、连线或归一化方式。

## 已确认的模块接口

两个 `2-D Lookup Table` 均使用以下归一化输入：

- 第一维：`N / 55090`，对应 `speed_bp`。
- 第二维：`m_in / 12.04`，对应 `m_ratio_bp`。

压比块读取 `PR_table`，效率块读取 `ETAT_table`。现有接线与数组维度一致，问题是表面数据中存在长平底、折角和不可信的外推形状。

## 论文锚点与可追溯性

论文《空间锂冷堆 He-Xe 布雷顿循环发电系统优化设计与运行特性分析》：

- 图 5.3：压缩机的压比和效率均为质量流量、转速的二维性能曲线。
- 表 5.2（§5.2.3）：压缩机稳态仿真结果为 `T_in=405.16 K`、`P_in=0.658 MPa`、`T_out=601.90 K`、`P_out=1.551 MPa`、`P_c=1231.6 kW`。
- §5.3.1：系统在约 230 s 达稳态，TAC 转速为 `55090 rpm`，压缩机功率约 `1.232 MW`。

因此设计查表点固定为：

- `N=55090 rpm`，即 `N/N_design=1.0`。
- `m_in=12.04 kg/s`，即 `m/m_design=1.0`。
- `PR=1.551/0.658=2.357142857`。
- `eta_c=0.84225`，由论文温压稳态数据和模型的 `gamma_hexe=5/3` 计算得到。

论文未公布每条非设计转速线的数值表；这些线将以图 5.3 的形态为约束构造为平滑代理曲线，并明确标记为此类代理数据，不能误称为论文原始数表。

## 方案

1. 保持 `speed_bp`、`m_ratio_bp` 及两个 Lookup Table 的二维接口不变。
2. 重建 `PR_table`：每个正转速线从低流量侧上升，在中高流量区域达到峰值，再向高流量侧平滑回落；全表不小于 1。
3. 重建 `ETAT_table`：每个正转速线仅有一个平滑峰值，峰值流量随转速单调右移，且效率全部位于 `(0,1]`。
4. 使 `(1.0, 1.0)` 的双线性插值严格匹配论文的压比与效率锚点。
5. 更新 MAT 元数据中的文献依据、设计点和版本说明；保留不参与 Lookup 的既有字段，避免破坏其他潜在读取方。
6. 使用测试先行：先写入能够拒绝旧表形状的回归测试，确认旧表失败；然后生成新表、写入 MAT，并验证通过。

## 验收条件

- 两张表与断点的维度匹配、断点严格递增，且数值有限。
- 两个表均保留现有二维接口和归一化定义。
- `(N/N_design,m/m_design)=(1,1)` 插值为 `PR=2.357142857`、`eta_c=0.84225`（允许仅限于浮点插值误差的容差）。
- 所有正转速线无长常数平底；压比曲线至多一个峰值，效率曲线恰为单峰拱形。
- 新生成的二维曲线图在视觉上具有论文图 5.3 的性能线族形态。
- 重新加载 `final_steady_24a.slx` 后，两个 Lookup Table 仍解析至对应变量且可通过模型更新检查。

## 范围外

- 不增加显式的入口温度、压力维度。
- 不修改透平、回热器、反应堆、负载或转子模型。
- 不宣称从图像恢复了论文未公开的非设计数值数据。
