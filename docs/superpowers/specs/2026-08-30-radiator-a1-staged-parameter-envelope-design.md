# 散热器 A1 分阶段参数包实验设计

**日期：** 2026-08-30

**状态：** 第 1—3 段已逐段获人工批准；完整书面规格等待最终文字复核

**验证对象：** 论文方案 B 的 NaK 回路与辐射散热器条件可行性，以及这些候选对第 5.3.1 节整机稳态的影响

**实施区域：** 仅 `tests/` 与 `tmp/`

**正式文件状态：** 本规格不修改 `final_steady_24a.slx`、正式 `.mat`、物性函数或任何正式 SLX

**前置设计：** `docs/superpowers/specs/2026-08-29-radiator-source-constrained-candidate-family-design.md`

## 1. 目的和完成边界

A1 不是一次“按论文曲线调参”的搜索，而是一次来源受限、变量受控、可追溯的两层候选实验：

1. 先用离线方程检查质量、能量、辐射能力和换热能力等必要条件；
2. 再把未被必要条件淘汰的固定代表参数包写入彼此独立的临时 SLX 副本；
3. 先进行 `500 s` 早期完整性筛查；
4. 只有通过 `500 s` 硬门的同一候选才允许继续到 `14000 s`；
5. 守恒、稳定性、论文差异和来源可信度分开报告；
6. 不按“最接近论文曲线”自动选择、调参或晋升候选。

本阶段即使全部实验通过，也只能证明某些**工程重构候选**在规定条件下可行，不能证明已经恢复徐驰论文作者的未公开参数或原始实现。

## 2. 证据口径

本规格沿用项目正式证据分级：

- ✅：本轮从原始文件、论文、NASA 报告或工具输出直接核实；
- ⚠️：来自相关但不同系统、不同材料状态或不同工作温区的一手资料，只能作为敏感性锚点；
- ❓：项目边界、条件反推、数学派生或明确批准的工程假设；
- ❌：没有可用独立来源，不得作为候选输入冒充论文事实。

必须始终区分：

- 论文直接公开量；
- NASA 来源技术分支；
- 当前项目继承边界；
- 条件反推量；
- 敏感性代理量；
- 作者实际但未公开的未知量。

反推值、条件闭合值和曲线数字化结果不能被重新包装成作者原始输入。结果更接近论文，也不能单独证明候选物理正确。

### 3.1 不可变源模型

✅ 每个临时候选都从以下受保护快照重新独立复制：

```text

```

本轮重新核对的 SHA256 为：

```text
0532e9ddf2deb7ef5e40cc1b8e619c44ea7afd36b00d807d118f4cd812a5a391
```

禁止从前一个候选继续修改生成下一个候选。不得跨候选继承保存后的模型状态、操作点、仿真缓存或重新求得的初值。

### 3.2 统一候选方程基线

所有代表分支统一使用已完成单变量验证的 NaK 积分焓差出口关系：

\[
\dot Q_{\rm NaK}
=
\dot m_{\rm NaK}
\left[H(T_{\rm in})-H(T_{\rm out})\right]
\]

其中 `H(T)` 由当前 NaK `cp(T)` 多项式解析积分得到。其身份固定为：

```text
exploration-only candidate baseline
paper_reproduced = false
formal_promotion = false
```

原始入口单点比热关系：

\[
\dot Q_{\rm NaK}
=
\dot m_{\rm NaK}c_p(T_{\rm in})(T_{\rm in}-T_{\rm out})
\]

只保留为历史对照，不参与候选优劣判断。A1 不把积分焓差候选宣称为作者原实现，也不复用该候选此前任何 `14000 s` 结果作为本轮证据。

## 4. 来源代表分支和变量身份

### 4.1 四个固定代表来源分支

进入离线筛选的分支固定为：

| 代表角色 | 分支 ID | `kappa`/(kg/m²) | 来源成熟度 |
|---|---|---:|---|
| 保守质量端 | `T300_fd1p45_one` | 4.22 | ✅ 已制造并试验 |
| 已试验双面端 | `T300_fd1p45_two` | 2.11 | ✅ 已制造并试验 |

“保守”和“乐观”只描述面密度及质量负担，不代表传热性能、寿命、制造可行性或动态稳定性优劣。

### 4.2 三类参数身份

每个参数包必须把以下三类输入分开存储，不得合并为一个没有来源标签的参数表：

1. **来源固定量**
   - `kappa`；
   - 材料分支；
   - 翅片密度；
   - 单面/双面口径；
   - 技术成熟度。
2. **论文直接边界**
   - 表 5.2 的 NaK 温度和部件功率；
   - 方案 B 质量约束；
   - 论文散热器质量、换热和辐射方程。
3. **工程假设轴**
   - `A_rad`；
   - `epsilon`；
   - `UA`；
   - `C_eff_proxy`；
   - `m_dot_NaK`；
   - `T_sink`。

工程假设轴中的数值必须保留具体身份；任何一点都不得称为“徐驰方案 B 原参数”。

## 5. 离线条件求解

### 5.1 方程

每个静态情景使用同一组集总关系：

```text
Q_NaK = m_dot * [H(Tin) - H(Tout)]

Q_NaK = h * A_exchange * (0.8*Tin + 0.2*Tout - Twall)

Q_NaK = epsilon * sigma * A_rad * (Twall^4 - Tsink^4)
```

第一轮固定：

```text
A_exchange = A_rad = A
UA = h*A
```

⚠️ 面积相等是为了不改变当前 SLX 拓扑而保留的工程假设，不是论文已经证明的几何关系。论文内换热面积与辐射面积应保持概念分离；如果 A1 证据表明该等同是主要限制，需要另立“面积拆分”结构实验并重新审批，不能在本轮顺手扩展。

给定 `m_dot`、`epsilon`、`T_sink` 和 `h` 后，条件求解只剩：

```text
Twall
A
```

求解根必须满足：

```text
Tsink < Twall < 0.8*Tin + 0.2*Tout
```

随后计算：

```text
M_rad = kappa*A
UA = h*A
```

无物理解、面积非正、壁温越界或质量违反必要上界的行直接淘汰，不进入临时 SLX。

### 5.2 NaK 流量情景

只设置两个身份明确的情景：

| 情景 | 数值 | 身份 |
|---|---:|---|
| `project_flow` | `6.95 kg/s` | ❓ 项目批准边界，不是论文直接值 |
| `energy_closure_flow` | `7.134146337 kg/s` | ❓ 固定论文表 5.2 端点、`1622 kW`及现行 NaK 物性的条件闭合值 |

不在两者之间插值，不按论文曲线接近程度选择流量。

使用论文表 5.2 的 `360.10 K → 609.58 K` 端点与当前 NaK 物性时：

```text
6.95 kg/s       → Q_NaK = 1580.132992 kW
7.134146337 kg/s → Q_NaK = 1622.000000 kW
```

第二个值只回答“若固定论文端点、论文部件功率和现行物性，需要什么条件流量”，不代表作者流量已经识别。

### 5.3 发射率锚点

采用：

```text
epsilon = 0.85
epsilon = 0.90
```

⚠️ NASA/TM-2008-215420 报告的碳—碳表面处理在其 `700–800 K` 设计温区给出 `0.85–0.90` 发射率。这些值在 A1 中仅为：

```text
NASA surface-treatment sensitivity anchors
```

徐驰方案 B 的材料、处理状态和主要壁温区没有由该来源唯一确定，因此不得写成 `Xu Chi scheme-B emissivity`。当前项目 `0.9` 只保留为上端对照。

### 5.4 冷源温度情景

SLX 候选只允许：

| 情景 | 数值 | 身份 |
|---|---:|---|
| `NASA_120_example` | `200 K` | ⚠️ NASA/TM-2007-215003 另一套约 100 kWe 系统算例 |
| `legacy_project` | `225 K` | ❓ 当前项目继承边界，未证明是论文方案 B 空间冷源 |

`0 K` 仅可作为离线理论最小辐射面积下界，不得写入任何 SLX 候选。

### 5.5 内部有效换热系数锚点

| 锚点 | `h`/(W/m²·K) | 身份 |
|---|---:|---|
| `legacy_inverse` | `9.755` | ❓ 当前项目由论文终点反算 |
| `NASA_120_low` | `200` | ⚠️ NASA/TM-2007-215003 异系统换热系数端点 |
| `NASA_120_high` | `600` | ⚠️ NASA/TM-2007-215003 异系统换热系数端点 |

NASA 算例约为 `199 kWt`、`859.3 K → 570 K`、`200 K` 冷源，不能把 `200/600` 称为徐驰参数。它们只用于检验：如果内部有效换热能力处于该 NASA 示例量级，条件面积与质量如何变化。

已批准的条件计算量级为：

- `h=9.755`：面积约 `1113–1186 m²`；
- `h=200`：面积约 `375–409 m²`；
- `h=600`：面积约 `340–372 m²`。

这些范围是条件计算结果，不是作者几何数据。


96 行必须全部输出，包括失败行。硬淘汰顺序固定为：

1. 无物理壁温根；
2. 面积、质量或 `UA` 非有限或非正；
3. `M_rad > 4650 kg`；
4. 理想辐射仍不能承担该情景的 `Q_NaK`；
5. 输入身份或单位不完整。

`4650 kg` 是方案 B 中 `M_rad + M_TAC` 的上界，而非已识别的散热器质量。因此：

```text
M_rad <= 4650 kg
```

只表示候选未被这一质量必要条件淘汰，不表示真实质量账已经闭合。

离线状态词只允许：

```text
rejected
not_rejected_under_necessary_conditions
unidentifiable_due_to_missing_input
```

不得使用 `validated`、`paper_matched` 或 `author_model`。

## 6. 有效热容代理量与时间尺度

目前不能用公开资料唯一识别完整散热器组件的有效比热。已核实的来源边界为：

- ✅ Toray T300 碳纤维数据表给出典型参考值 `777 J/(kg·K)`，但不是完整热管散热器组件；
- ⚠️ NASA K1100 复合翼片分析使用 `1000 J/(kg·K)`，对象不是 NASA/TM-2008-215420 的完整钾热管组件；
- ⚠️ NASA 封装 APG 材料资料给出室温约 `840 J/(kg·K)`，同样不是完整组件；
- ❌ P95 WG 完整热管组件的唯一有效比热尚未找到；
- ❌ NASA/TM-2008-215420 的总质量含多种结构材料和工作流体，不能把单一纤维比热直接当作整机 `Cp_rad`。

因此动态代表包只使用三种敏感性代理量：

```text
Cp_proxy = 777 J/(kg*K)   # T300纤维低端参考
Cp_proxy = 900 J/(kg*K)   # 当前项目继承对照
Cp_proxy = 1000 J/(kg*K)  # NASA K1100层合翼片高端参考
```

每个代表包的组合量为：

```text
C_eff_proxy = M_rad * Cp_proxy
```

机器可读字段和报告名称必须包含 `proxy`，不得写成作者壁材比热。

图 5.18(d) 的 `120–150 s` 时间尺度只能用于：

```text
tau_predicted = C_eff_proxy / G_effective
```

的方向性/相容性比较，以及后续动态结果比较。不得用该曲线反算 `Cp_proxy`，再把同一曲线当作独立验证成功。

为消除 96 行与动态时间尺度之间的歧义：`Cp_proxy` 不参与 96 行静态全排列。只有固定的 12 个代表角色在其静态行未被淘汰后才附加相应 `Cp_proxy`，并在创建 SLX 前检查 `C_eff_proxy` 和预测时间尺度是否有限、为正且单位完整。

## 7. 十二个固定代表参数包

每个材料分支最多选择三个角色固定的参数包：

| 角色 | 流量/(kg/s) | `epsilon` | `T_sink`/K | `h`/(W/m²·K) | `Cp_proxy`/(J/kg·K) | 作用 |
|---|---:|---:|---:|---:|---:|---|
| `legacy_transfer` | 6.95 | 0.90 | 225 | 9.755 | 900 | 保留当前传热能力的守恒对照 |
| `conservative_source` | 7.134146337 | 0.85 | 225 | 200 | 1000 | 高热负荷、低发射率、较高热容 |
| `optimistic_source` | 6.95 | 0.90 | 200 | 600 | 777 | 低热负荷、高发射率、高换热能力、低热容 |

因此最多：

```text
4个来源分支 × 3个固定角色 = 12个500 s临时候选
```

每个参数包的 `A`、`UA` 和 `M_rad` 必须由其条件方程求得，不得手工指定。

代表包生成规则必须是确定性的。同一份 96 行输入重复运行必须产生完全一致的：

- 候选 ID；
- 排序；
- 参数值；
- 选择理由；
- 输出文件哈希。

如果某个固定角色对应的静态行已经被淘汰：

- 不创建其 SLX；
- 在代表矩阵中保留失败原因；
- 不以另一个更容易通过的点补位；
- 不放宽参数包络以凑满 12 个。

如果最终不足 12 个，只运行实际通过离线硬门的候选，并明确报告“批准包络内代表候选不足 12 个”。

- NaK 物性多项式；
- 质量流量定义；
- 状态初值；
- 外部输入时间表；
- 求解器和容差；
- 温度限制；
- 断言边界；
- 任何反馈、控制器、补偿或目标回注。

如果某候选只有改变受保护项才能运行，则该候选失败，不扩大 A1 授权。

## 9. 500 s 阶段

### 9.1 阻塞式完成检查

每个候选必须阻塞等待仿真完成，不能只证明 MATLAB 命令已经发出。

出现以下任一情况即失败：

- MATLAB/Simulink 返回错误；
- 实际停止时间小于 `500 s`；
- `ErrorMessage` 非空；
- 关键状态或信号出现 `NaN`、`Inf` 或复数；
- 触发压气机、物性、流量或温度断言；
- 散热器出口求根不存在物理包围区间；
- 出口温度高于入口温度且与规定热流方向冲突；
- 温度低于批准的物性或求根下界；
- 辐射、流体—壁面换热或焓差热流符号矛盾；
- NaK 散热器焓差—对流残差不小于 `1 W`；
- 冷却器—散热器整环残差不小于 `1 kW`；
- 末窗温度或功率斜率持续增大；
- 状态导数持续发散；
- 结构差异超出白名单；
- 受保护或正式文件哈希变化。

只有同时满足以下条件才进入 `14000 s`：

```text
actual_final_time == 500 s
ErrorMessage == empty
all_required_signals_are_finite == true
property_domains_respected == true
radiator_enthalpy_convection_residual_W < 1
cooler_radiator_loop_residual_W < 1000
no_persistently_growing_end_window_slope == true
protected_hashes_unchanged == true
```

### 9.2 禁止的失败后自适应动作

失败后不得自动：

- 换求解器；
- 缩小步长直到“能跑”；
- 增加限幅或饱和块；
- 调整初值；
- 改流量；
- 修改其他模块；
- 根据论文误差反调参数；
- 扩大已批准包络。

如果失败明确属于共同工装错误，例如日志变量拼写错误，可以修复工装，但必须：

1. 记录工装错误和修复；
2. 对全部受影响候选应用同一修复；
3. 从头重跑全部受影响候选；
4. 不改变任何物理参数包。

## 10. 14000 s 推进合同

通过 `500 s` 的候选必须使用与短算例完全相同的：

- 候选模型文件；
- 参数包；
- 初始状态；
- 外部输入；
- 求解器；
- 数值容差；
- 模型结构；
- 物性函数；
- 日志定义。

不允许在 `500 s` 和 `14000 s` 之间重新保存模型、求稳态操作点、修改参数或生成另一模型变体。停止时间应通过不改变模型物理内容的统一运行配置控制；候选模型文件本身保持同一 SHA256，并在两次运行前后核对。

`14000 s` 同样必须阻塞等待，并核验：

```text
actual_final_time == 14000 s
ErrorMessage == empty
all_required_signals_are_finite == true
protected_hashes_unchanged == true
```

未通过 `500 s` 的候选不生成长算例变体，也不进行“试试看长期是否自稳”的补跑。

所有通过短门的候选都进入长算例；不得先按论文误差筛掉来源更强但曲线不够接近的候选。

## 11. 结果报告合同

每个候选必须并列报告四类结果。

### 11.1 数值完整性

- 是否实际跑到停止时间；
- `ErrorMessage`；
- 是否存在非有限/复数状态；
- 断言和物性域状态；
- 求解器统计；
- 关键状态最大/最小值；
- 早期峰值和异常导数。

### 11.2 物理守恒

- NaK 入口—出口积分焓差；
- 散热器流体—壁面换热；
- 壁面对环境辐射；
- 冷却器冷侧换热；
- NaK 闭环残差；
- 壁面储热项；
- 最终窗口能量残差。

能量残差必须由独立分析代码根据记录信号复算，不能只读取候选内部用于求解的同一个残差信号。

### 11.3 论文比较

- 表 5.2 可观测温度和功率；
- 图 5.18(d) 可数字化温度点；
- 图 5.19 对应功率曲线；
- 上升/下降方向；
- 初始平台；
- 超调或下冲；
- 达稳时间；
- 稳态终值；
- 必要时的归一化曲线形状指标。

表 5.2 NaK 端点和 `1622 kW` 已参与条件设计，不能再次计作独立验证成功。真正具有区分力的是闭环内其他温度、功率、时间尺度和全系统副作用。

### 11.4 来源与可解释性

- 来源分支；
- 论文直接输入；
- NASA 技术分支；
- 项目批准边界；
- 条件反推量；

- 仍不可识别的作者输入；

四类结果不得相互替代：

- 能量守恒通过不等于论文曲线通过；
- 曲线接近不等于来源正确；
- 来源可靠不等于候选稳定；
- 仿真跑完不等于物理正确。

## 12. 多候选与零候选处理

### 12.1 多个候选通过

如果多个候选通过 `14000 s`：

1. 不自动选择论文误差最小者；
2. 先按证据等级排序：
   - 论文直接；
   - 已试验来源分支；
   - 已制造未试验；
   - 推演；
   - 纯敏感性；
3. 同一证据等级内再比较：
   - 质量裕度；
   - 能量残差；
   - 数值稳定性；
   - 论文表格误差；
   - 曲线形状误差；
4. 独立证据不能区分时，明确报告：
   - “存在多个条件可行参数包”；
   - “作者实现仍不可唯一识别”。

不得隐藏非唯一性并宣布一个所谓“最佳参数”。

### 12.2 没有候选通过

如果所有代表候选均失败，固定结论为：

> 在当前来源分支、批准参数包络、固定 NaK 积分焓差候选和现有整机结构下，没有找到同时满足早期数值完整性与物理门的代表候选。

此时必须：

- 保留全部失败证据；
- 不自动扩大参数包络；
- 不修改论文验收标准；
- 不恢复旧的散热器终点反算参数作为所谓修复；
- 不在没有独立证据时把失败归咎于单一变量；
- 根据失败聚类，另行决定补来源、修工装或重新审查模型结构，并重新申请授权。

## 15. Wolfram 独立验证边界

默认由当前项目代码完成数学计算。只有在以下情况下才调用 Wolfram 做第二实现验证：

- 积分或符号消元复杂；
- 多根问题或数值稳定性存疑；
- 结果将直接影响正式模型修改；
- 结果将支撑关键研究结论。

简单、可单元测试复算的包络算术不需要为了形式完整而强制调用 Wolfram。若调用，必须记录输入、假设、输出和与项目实现的差异，不能把 Wolfram 结果直接当作文献证据。
