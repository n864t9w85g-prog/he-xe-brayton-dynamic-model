# 转动机械查表受控候选对照实验设计

日期：2026-09-02

状态：方案 A 已获用户批准；本文件等待书面规格复核

实验区：仅 `tests/` 与 `tmp/`

## 1. 目的

当前任务只回答一个主线问题：在不改变论文物理机制、不引入额外控制器且不修改正式模型的前提下，替换明显不符合论文曲线形状或来源不闭合的压气机/透平查表，是否能够使 `final_steady_24a.slx` 的稳态结果向论文第 5.3 节及表 5.2 明显收敛。

本实验不是寻找任意“能跑通”的参数组合，也不声称恢复了徐驰作者的原始查表数据。

## 2. 已确认的证据边界

- ✅ 当前压气机表的全部压比速度线在流量轴上严格单调下降，而论文图 5.3 的图标显示具有峰值/拐点的速度线；因此当前表不能视为论文图 5.3 的数值复刻。
- ⚠️ 当前透平表的流量饱和趋势和效率驼峰与论文图 5.5 定性接近，但仓库中没有其原始数据、几何输入或生成脚本，来源身份未闭合。
- ⚠️ 本机恢复的 `Xu2022_PaperStyle_Equivalent_Lookup.mat` 使用论文第 5 章稳态锚点和 He-Xe 物性确定绝对尺度，非设计曲线形状来自 Gallo 等 2007 年同工质小型 BRU 曲线的数字化与缩放；100%–110% 区域为显式线性外推。
- ⚠️ 本机恢复的 NASA D-8063 透平包具有源代码、69 个输出点和处理脚本，但采用 NASA 典型径向透平几何，并扫描 `PD/XK` 使最大效率接近 0.87；其脚本还把设计流量写成 4.572 kg/s，而论文表 5.2 的能量平衡约束对应约 12 kg/s。因此它只作为独立趋势参考，不直接接入整机候选。
- ❌ 本地 Git 对象、废纸篓、Spotlight 索引和可见本机副本中均未发现徐驰作者原始 breakpoint、table matrix 或完整目标机几何输入。

## 3. 固定候选与禁止事项

### 3.1 固定候选

唯一允许接入临时整机副本的候选是恢复的 `Xu2022_PaperStyle_Equivalent_Lookup.mat`。其角色是“证据受限的等效重建候选”，不是作者原表。

NASA D-8063 包仅用于离线核对透平流量随膨胀比的方向、效率峰形和范围，不参与临时整机查表替换。

### 3.2 禁止事项

- 不修改 `final_steady_24a.slx`、`final_dynamic_24a.slx` 或正式 `.mat`。
- 不修改 `HeXe_property_simulink.m`。
- 不增加控制器、校正反馈、状态回注或曲线补丁。
- 不扫描、拟合或人工微调候选表中的单元格。
- 不同时改动热交换器、反应堆、散热器或压力闭合参数。
- 不因曲线更接近论文便宣称候选物理正确。
- 不在 500 s 门失败后继续进行 14000 s 长跑。

## 4. 实验矩阵

所有实验使用由官方 MATLAB/Simulink API 创建或加载的临时模型副本，不直接编辑 `.slx` 内部 XML。

| 组别 | 压气机表 | 透平表 | 唯一变化目的 |
|---|---|---|---|
| C0 | 当前正式表 | 当前正式表 | 固定当前基线 |
| C1 | 论文式等效候选 | 当前正式表 | 隔离压气机查表影响 |
| C2 | 当前正式表 | 论文式等效候选 | 隔离透平查表影响 |
| C3 | 论文式等效候选 | 论文式等效候选 | 检查联合闭合与交互作用 |

不得在上述四组之外派生额外参数组合。若候选变量命名、维度或方向与当前模型不一致，只允许进行可逆的轴转置、变量别名和单位换算；任何换算必须写入映射清单并用设计点单元测试证明，不得改变表面数值。

## 5. 执行顺序与判定门

### Gate 0：来源固化

将恢复材料复制到 `data/provenance/rotating_machinery/recovered_20260902/`，记录原始位置、文件尺寸、修改时间、SHA256、来源声明和限制。原始压缩包与关键 MAT/CSV/脚本都需有哈希记录。复制行为不得改变文件内容。

### Gate 1：离线查表审计

对 C0 与候选表生成统一指标和图：

- 断点范围、维度、NaN/Inf、效率范围；
- 55090 rpm 设计点的压比、流量和效率；
- 每条速度线的单调区间、峰值位置、喘振侧与堵塞侧趋势；
- 论文运行转速 22036、50610、55090、57844.5、59655 rpm 的域覆盖；
- 与论文图 5.3/5.5 的定性形状约束；
- 与论文表 5.2 的设计点误差。

硬失败条件：维度/方向无法无歧义映射、含非有限值、关键运行域越界、效率超出物理范围，或设计点误差超过 5%。

### Gate 2：临时模型结构与 500 s 运行

对 C0–C3：

1. 用 API 检查查表块、输入信号和变量映射。
2. 更新模型并记录编译错误。
3. 运行固定 500 s，不改变求解器、初值或其他物理参数。
4. 记录全部现有稳态验收信号、查表输入域、断言、停止原因和最后有效时刻。

硬失败条件：无法编译、非有限量、查表越界、断言终止、比 C0 更早失败，或主要论文稳态指标整体恶化。

“明显改善”定义为：在相同可比较指标集合上，表 5.2 归一化绝对误差的中位数至少下降 20%，且没有任一关键指标由通过 ±5% 退化为不通过。若 C0 本身不能运行到 500 s，则比较共同有效时间窗，并把“推进到更晚时间”单独报告，不与数值吻合混为一谈。

### Gate 3：14000 s 推进

只有同时通过 Gate 1、Gate 2 且满足“明显改善”的组别才允许运行 14000 s。若多组通过，只推进误差最小且改动最少的一组；优先级为 C1/C2 单变量组高于 C3 联合组。

14000 s 结果按论文第 5.3 节稳态运行特性和表 5.2 对比，不用第 5.4 节瞬态指标替代稳态判定。第 5.4 节动态任务仅在稳态基线通过后恢复。

## 6. 输出与可追溯性

实验输出固定包括：

- `candidate_mapping.json`：候选变量到模型查表块的映射、转置和单位换算；
- `offline_map_audit.json/csv` 与统一对比图；
- C0–C3 每组的运行清单、MATLAB 日志、停止原因、最后有效时刻和信号 CSV；
- `steady53_candidate_comparison.md`：证据等级、数值门结果、论文差异和结论；
- 输入文件 SHA256、MATLAB/Simulink 版本、模型副本 SHA256 和 Git commit。

临时运行输出保存在 `tmp/rotating_map_candidate_A_20260902/`。可复用的审计脚本和小型判定结果可放入 `tests/`；大体积运行产物不提交 Git。

## 7. 结论用语

实验只允许得出以下三类结论：

1. “候选未改善或引入新失败，判败”；
2. “候选在探索区改善了稳态复现，值得进入正式重构审查”；
3. “证据不足，无法区分候选与当前表”。

即使 C3 通过 14000 s，也不得直接写成“恢复了作者原始查表”或“已经复现论文模型”。正式模型晋升仍需单独记录论文/物理依据、最小 API 修改、前后对比和人工批准。

## 8. 完成条件

本实验在以下任一条件满足时结束：

- 所有候选在 Gate 1 或 Gate 2 判败，并形成可复核失败证据；
- 某一最小候选通过 14000 s，并形成稳态论文对比报告；
- 发现轴/单位/数据来源歧义，现有证据无法无歧义解决，记录阻塞并停止接入。

不以“跑完脚本”作为完成条件；必须给出哪张表、哪种变量映射、哪一项论文指标改善或失败的可讲述证据链。
