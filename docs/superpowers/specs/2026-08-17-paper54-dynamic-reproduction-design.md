# 徐驰论文第 5.4 节动态模型复现设计

## 目标

以徐驰论文表 5.2 作为全功率稳态基线约束，以第 5.4 节图 5.27 至图 5.34
作为动态验收依据，使 `final_dynamic_24a.slx` 在可重复运行条件下复现论文的稳态点、
扰动时序、响应方向和论文明确给出的扰动后稳态值。

“复现成功”不得仅指曲线趋势相似。模型必须先满足功率守恒、部件接口状态、查表范围
和稳态残差要求，之后才能比较动态响应。

## 学术可追溯性规则

进入正式模型的每个数值必须属于以下类别之一，并在代码或数据元信息中标注类别：

1. **论文直接值**：论文正文、公式、表格或图注明确给出的数值。
2. **可重复计算值**：只使用论文直接值和论文公式计算得到的结果；必须保存完整计算式。
3. **论文图数字化值**：从论文原图坐标和曲线提取；必须保存原图页码、曲线名称、
   坐标标定点、提取数据和数字化误差。
4. **当前模型诊断值**：只用于定位故障，不能作为论文参数写回模型。

禁止把人为调参、手工平滑曲线、经验猜测或优化器为了缩小误差产生的自由参数冒充论文数据。
若论文没有给出足以唯一确定某个参数的数据，只能：

- 保留符号参数并报告不可辨识性；或
- 使用论文其他数据反算，并明确标为“可重复计算值”；或
- 从论文原图数字化，不得凭视觉印象生成代理曲线。

现有 `hexe_compressor_lookup.mat` 的非设计点曲线是人工构造的 Gaussian 代理曲线，
只能作为故障诊断临时数据，不能作为最终论文复现图谱。

## 论文约束

### 表 5.2 稳态约束

- TAC 转速：`55090 rpm`（第 5.3.1 节正文）。
- 压缩机入口：`405.16 K`、`0.658 MPa`。
- 压缩机出口：`601.90 K`、`1.551 MPa`。
- 压缩机功率：`1231.6 kW`。
- 透平功率：`2252.2 kW`。
- 发电功率：`1000.21 kWe`。

压缩机设计压比必须由表 5.2 直接计算：

```text
PR_design = 1.551 / 0.658 = 2.357142857...
```

`PR=1.92` 属于论文其他设计阶段或其他工况，不得替代表 5.2 的第 5 章仿真设计点。

### 转子功率约束

论文式（5.17）和（5.18）为：

```text
P_TAC_X = P_T - P_C - P_load
dN_rpm/dt = 900*P_TAC_X/(pi^2*I_TAC*N_rpm)
```

表 5.2 的发电功率单位是 `kWe`，而转子功率平衡需要轴侧机械负载。两者不得在没有
效率定义的情况下直接混用。由表 5.2 三个功率反算的发电机效率为：

```text
eta_generator = 1000.21 / (2252.2 - 1231.6)
              = 0.980021555947...
```

该值属于“可重复计算值”，不是论文直接给出的发电机效率。正式实现必须保存上述计算式，
并将外部调度量命名为电功率 `P_electric`，转子扣除量命名为轴功率
`P_shaft = P_electric/eta_generator`，避免单位语义混淆。

### 第 5.4 节动态约束

- 稳定点转速扰动：在稳态运行 `500 s` 后施加 `55090 rpm` 的 `+5%` 或 `-5%`
  扰动，转速应返回 `55090 rpm`。
- 负载工况：`0-500 s: 1000 kW`，`500-1500 s: 950 kW`，
  `1500-2500 s: 1000 kW`，`2500 s` 后 `1050 kW`。
- 负载工况论文稳态转速：`55090 -> 59655 -> 55090 -> 50610 rpm`。
- 反应性工况：`500 s: +0.0001`，`2000 s: -0.0001`，
  `3500 s: 0`，`5000 s: +0.0003`。
- 反应性工况论文稳态转速：`55090 -> 56000 -> 54300 -> 55090 -> 57790 rpm`。

## 实现边界

### 1. 可重复测试层

新增 MATLAB 测试，分别验证：

- 压缩机在表 5.2 强制入口条件下的出口温度、出口压力和功率；
- 表 5.2 三个功率经过电功率到轴功率换算后的转子残差为零；
- 整机基线在 `500 s` 内保持 `55090 rpm`，且所有关键热工状态有限并位于物性范围；
- 压缩机和透平运行点始终位于数字化图谱范围，不允许静默限幅；
- 第 5.4 节负载和反应性时序与论文一致；
- 扰动后稳态转速达到论文给出的数值，误差容限由论文曲线分辨率确定，不能任意放宽。

### 2. 转子和负载层

修改 `final_dynamic_24a.slx` 的 TAC 转子输入语义，在转子求和前显式完成
`P_electric -> P_shaft` 换算。保留论文式（5.18）的惯量和转速微分结构。

`eta_generator` 在初始化脚本中通过表 5.2 计算，不以无来源小数字面量写入模型。

### 3. 耦合稳态层

在正确功率定义下求解全模型稳态。稳态求解的目标不是随意拟合表 5.2，而是寻找满足
现有守恒方程且同时达到论文边界条件的状态。如果不存在这样的状态，逐组件输出残差，
定位违反论文约束的方程或参数，只修改有来源证据的根因。

第 5.4 节扰动从全功率稳态开始，因此允许把经过验证的全模型稳态操作点作为动态工况
初态；不得把冷启动初值和全功率稳态初值混为一组。

### 4. 部件图谱层

压缩机和透平非设计点只能来自论文引用的原始公开图谱，或论文中确实绘出了性能坐标和
曲线的图。论文图 5.3 是压缩机 Simulink 模型框图，图 5.4 是压缩机封装子系统，二者都
不是性能图谱，不得从中生成查表数据。优先使用更清晰的原始公开数据；数字化过程保存为
可审计数据文件和脚本。

不得为了命中第 5.4 节几个终点而直接构造穿过终点的曲线。第 5.4 节终点只用于独立验收，
不能与图谱提取数据同时作为无约束拟合目标。

#### 压缩机公开源图谱与高转速延伸

NASA TN D-7487 是论文引用的非设计计算方法，但正式运行该程序需要 28 项输入。
当前目标压缩机审计仅闭合 15 项，余下 13 项几何或经验输入没有公开来源，因此不得
用 D-7487 附带的空气算例、流动角替代金属角、有效面积替代几何喉部面积，或用反算值
填补缺项。

正式候选图谱改用已经逐点数字化的 NASA TM X-2269 氩气实测 50%--100% 转速线，
再通过无自由参数相似变换映射至论文表 5.2 的 He-Xe 设计点。TM X-2269 数据必须标成
公开源压缩机实测数据，不能宣称为徐驰论文压缩机的原始试验数据。

论文第 5.4 节最高稳态转速为 `59655 rpm`，相对表 5.2 的 `55090 rpm` 为
`1.0828644037`，超过 TM X-2269 的 100% 实测线。对
`s=N_corrected/N_design`，只允许在 `1 < s <= 1.10` 使用下列无自由参数延伸：

```text
flow_s = s * flow_100
PR_s = [1 + s^2 * (PR_100^a_source - 1)]^(1/a_source)
eta_s = eta_100
```

其中 `a_source=(gamma_source-1)/gamma_source=2/5`。`s=1` 必须逐点返回原 100%
数字化线；`s>1.10` 必须报错，不得静默限幅。生成的 100% 以上数据来源类别必须是
`similarity_prediction`，而不是 `measurement`。

同一纯计算函数允许在测试中以 `s=0.9` 执行留一预测，但该输出必须标成
`validation_prediction` 和 `model_use_approved=false`。候选图谱在 100% 以下只能采用
对应 NASA 数字化实测线，不得把验证预测写入正式 MAT。

该规则用 100% 实测线留一预测 90% 实测线进行独立检查。检查点取 90% 数字化线排序后
的第 3--5 个点，并以 `phi=flow_90/0.9` 找到 100% 基准值。当前数字化数据得到：

```text
pressure ratio: MAE = 0.0228671267225498, max = 0.0322228459018734
efficiency:     MAE = 0.00441873824420987, max = 0.00565366047760163
```

这些误差只验证 10% 跨距内相似延伸的量级，不参与调整公式，也不允许成为新的拟合参数。
第 5.4 节的任何终点均不得出现在候选图谱的校准输入或生成元数据中。

#### 候选图谱门禁与坐标修正

候选 MAT 必须写到 `output/paper54_reproduction/`，不得由构建器直接覆盖活动
`hexe_compressor_lookup.mat`。候选图谱只在以下检查全部通过后才允许经单独的、可审计的
应用步骤替换活动文件：来源哈希、数字化覆盖、相似延伸、查表有效域、表 5.2 强制点、
模型更新和活动文件备份。

压缩机查表输入必须改成温压修正坐标：

```text
N_corrected_ratio = (N/N_design)/sqrt(T_in/T_design)
mdot_corrected_ratio = (mdot/mdot_design)*sqrt(T_in/T_design)/(P_in/P_design)
```

当前 `N/55090` 与 `mdot/12.04` 只在表 5.2 入口温压恰好成立，不能继续作为正式动态
坐标。查表域外必须显式失败并记录运行点，不允许使用端点钳位伪装为有效预测。

### 5. 运行和报告层

修正 `run_dynamic.m` 中错误的 `PR=1.92` 说明和负载恢复时间。运行脚本分别产生基线、
转速扰动、负载扰动和反应性扰动结果，并保存关键状态、功率残差、查表坐标和来源清单。

过时的验收文档必须同步修正，但不得删除历史失败证据。

## 验收标准

最终必须同时满足：

1. 表 5.2 压缩机、透平和发电功率之间的轴侧功率残差在数值容差内为零。
2. 压缩机强制设计点达到表 5.2；整机稳态压缩机入口也达到同一论文状态。
3. `55090 rpm`、`rho=0`、`1000 kWe` 基线运行不漂移，不触发物性钳位或查表越界。
4. 第 5.4 节三个扰动工况均能完成，时序与论文一致。
5. 论文明确给出的扰动后稳态转速在由原图分辨率确定的容差内复现。
6. 所有进入正式模型的数值都有论文位置、计算式或数字化证据；不存在未标注的调参值。

若某个动态量无法复现，不得宣称整体成功。继续追踪该量的输入、方程、图谱和状态残差，
直到找到可验证根因并完成修正。
