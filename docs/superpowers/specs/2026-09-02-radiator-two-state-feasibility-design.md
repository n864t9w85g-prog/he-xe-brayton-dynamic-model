## 3. 比较过的路线

### 方案 A：积分方程正参数可行性门（采用）

直接对数字化曲线逐区间积分式(5.15)，把未知量限制为常数：

- `C_fluid > 0`，单位 J/K；
- `UA > 0`，单位 W/K。

优点是无需假定流体质量、无需 SLX、可给出符号层面的反证；缺点是只能判断此方程族是否可行，不能恢复作者唯一参数。

会同时引入 IHX、预冷器、回热器、边界时序和初值差异，不能判断散热器方程是否成立。

## 4. 冻结输入与两种能量口径

### 4.1 论文曲线与边界

- 入口温度固定为表 5.2 的 `T_in=609.58 K`。
- 壁温和出口温度只读自固定数字化 CSV；不平滑、不移动时间轴、不删点。
- 保留原读图说明 `±3 K、±2 s`；它不是新的验收阈值。
- 只检查两个已有流量身份：
  - `6.95 kg/s`：项目批准边界，不是论文直接值；
  - `7.134146337 kg/s`：固定论文端点、1622 kW 与现行 NaK 物性的条件闭合值，不是作者流量。
- 不在两者之间插值，不扩展流量包络。

### 4.2 平均温度定义

按论文式(5.15)：

```text
T_bar = 0.8*T_in + 0.2*T_out
```

### 4.3 主口径与独立敏感性口径

主口径复现当前 SLX 的流动能量算法：

```text
cp_NaK(T) = 1000*(1.061 - 3.694e-4*T + 4.615e-8*T^2
                  + 1.509e-10*T^3)
Q_flow = m_dot * cp_NaK(T_in) * (T_in - T_out)
```

独立敏感性口径使用同一个现行 NaK 多项式的解析焓差：

```text
Q_flow = m_dot * [H_NaK(T_in) - H_NaK(T_out)]
```

两者是预先固定的数值实现对照，不是按结果选择的参数分支。现行 NaK 多项式具有来源支持但不是已恢复的作者源代码；结果必须保持这一身份。

## 5. 积分方程

对相邻数字化点 `a→b`，论文流体储热式写成：

```text
C_fluid * d(T_bar)/dt
  = Q_flow(T_out) - UA*(T_bar - T_wall)
```

逐区间积分：

```text
A_i*C_fluid + B_i*UA = D_i

A_i = T_bar,b - T_bar,a
B_i = integral_a^b (T_bar - T_wall) dt
D_i = integral_a^b Q_flow dt
```

`B_i` 和 `D_i` 使用相邻数字化点的梯形积分。不得从曲线反解 `C_fluid/UA` 后再用同一曲线声称独立验证成功。

## 6. 两级可行性检查

### 6.1 第一级：无拟合的符号必要条件

对 `A_i>0`、`B_i>0` 的升温区间，正流体热容要求：

```text
UA < D_i/B_i
```

对名义平台区间 `A_i=0`，方程要求：

```text
UA = D_i/B_i
```

若平台所需 `UA` 大于任一早期升温区间允许的上界，则不存在正的恒定 `C_fluid` 和 `UA`。这个结论不依赖流体质量猜测，也不需要设置拟合误差阈值。

### 6.2 第二级：全区间线性一致性

无论第一级结果如何，都记录：

1. 全区间无约束最小二乘解及参数符号；
2. 二变量非负约束最小二乘解；
3. 每区间能量残差、总平方残差和相对残差；
4. 各区间单独反推的条件 `C_fluid(UA)` 相容性；
5. 若 `C_fluid>0`，用现行 `cp` 换算的条件质量，仅标为诊断量。

对得到的正参数候选，逐区间枚举两端出口温度、壁温及时间的读图角点，计算该候选的残差范围。只有每个区间的残差范围都包含零，才称为“区间局部相容”。该检查故意允许相邻区间对共享点选择不同角点，因此比一条全局一致曲线更宽松；通过也不能证明存在唯一全局曲线。

二变量非负解使用解析二维边界比较实现，不依赖随机初值、优化器容差或外部拟合工具。计算结果以独立重排公式和高精度算术复核；本问题不需要调用 Wolfram。

## 7. 读图敏感性

### 7.1 温度读图余量

对每个区间枚举两端出口温度与壁温的 `±3 K` 角点，分别求：

- 早期 `D_i/B_i` 的最大允许上界；
- 平台 `D_i/B_i` 的最小所需值。

该枚举故意给予各区间比全局一致曲线更大的独立自由度。若在这种有利于恢复可行性的条件下仍发生上界冲突，才标记为“对温度读图余量稳健不相容”。

### 7.2 时间读图余量

第一级的 `D_i/B_i` 中区间时长在同一梯形积分比值内抵消，因此 `±2 s` 不影响符号上界比较。第二级另报告按相邻点时间角点形成的积分系数范围；不把独立时间角点冒充一条全局唯一时间轴。
时间角点只接受保持原点序且区间时长严格为正的组合。

## 8. 结果分类

结果只能属于以下之一：

1. `constant_positive_two_state_robustly_infeasible`
   - 两个流量身份、两种能量口径的名义必要条件均冲突；
   - 在有利的 `±3 K` 角点下仍冲突；
   - 不建立两状态 SLX，根因转向未公开边界时序、时变/分布式换热或论文实现差异。
2. `constant_positive_two_state_nominally_infeasible_but_reading_sensitive`
   - 名义曲线冲突，但读图角点可解除；
   - 需要提高论文曲线数字化精度，不能修改模型。
3. `constant_positive_two_state_conditionally_feasible`
   - 第一级必要条件不冲突、无约束解的两个参数均为正，且同一候选在每个区间的读图角点残差范围都包含零；
   - 参数仍是由图 5.18(d)条件识别的候选，不是作者值；另立规格后才可建立临时 SLX。
4. `constant_positive_two_state_full_interval_inconsistent`
   - 第一级必要条件不冲突，但无约束解出现非正参数，或不存在一个正候选使全部区间的读图角点残差范围包含零；
   - 不建立临时 SLX，继续检查固定边界和常 `UA` 假设。
5. `evidence_contract_failure`
   - 输入哈希、列名、点数、单调时间、单位、非有限值或实现交叉复核失败；
   - 不产生科学结论。

不得为了得到“可行”结论修改分类门、删点或改变读图余量。
