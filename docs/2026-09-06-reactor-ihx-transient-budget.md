**❓ 末点约17.183 kW的“燃料传热−IHX向He-Xe传热”差额，主要来自上游热量定义不一致，不是尚未消失的储热。早期两端功率差则确实包含显著储热，不能直接按不守恒判错。**

## 范围及复用身份

✅ 本轮读取2026-09-02保存的14000 s基线signals.csv、已导出的states.csv和只读模型清单，共211个对齐样本。正式SLX哈希仍为31745b64…；运行使用的液锂物性是冻结版本ORNL×0.9615。本轮固定这个真实运行口径，没有混用根目录无倍率物性，没有新仿真或模型修改。

✅ 本轮重新核对两区液锂积分器的容量、热流分配、流量、温差及比热连线。每区两个液锂状态各使用 `m_region cp(T_mean)/2`，各扣除 `Q_hot/2`。原模型壁面换热分别为 `h_Li A(T_hot_mean−T_wall)` 和 `h_HeXe A(T_wall−T_cold_mean)`。这些是当前实现事实，不等于已证明作者离散化与之相同。

## 分解方法

❓ 先从堆功率扣除燃料储热，得到燃料向外传热Q_f。再按同一时刻的液锂温度和流量计算冻结物性焓差Q_b，并按模型两区平均温度比热计算对流项Q_a。记IHX热侧到壁面的热量Q_h，壁面到He-Xe的热量Q_c，则：

```
Q_f − Q_c = (Q_f − Q_b) + (Q_b − Q_a) + (Q_a − Q_h) + (Q_h − Q_c)
               上游口径差      分区比热近似差       液锂模型储热       壁面储热
```

❓ 液锂模型储热由逐状态微分方程右端重建，再乘各自模型容量求和。它不是独立量热观测，也不自动等于真实流体内能变化；分解式闭合本身是代数检查，不能拿来证明物理模型正确。壁面储热按其热流差重建。

❓ 此时燃料自身储热另为0.000173 W。IHX各液锂和壁面状态的微分方程右端绝对值均小于1.5e−9 K/s，最后一段约140.85 s的温度割线斜率绝对值小于1.1e−9 K/s。两类检查都支持末点储热很小；割线不是瞬时导数，两者不要求逐项精确相等。

❓ 因此，在这个基线与模型定义下，继续延长运行时间不能合理解释或消除约17.17 kW的上游口径差。该差额也不能冒充论文2664与2647.18 kW之间16.82 kW差额的解释，两者工况与定义不同。

## 结论边界与后续约束

✅ 本轮把“是否只是还未稳态”的疑问落实到了已有运行的储热项，而不是凭曲线外形判断。❓ 结论仍支持先前定位：反应堆内部81.219 kW差额与跨物性口径差额部分抵消，造成约17.17 kW净差；应分别处理，不能把较小净差当作内部已经一致。

❓ 约12.744 W是当前温区、当前离散状态下的分区比热近似差，不能据此承诺冷启动或全部扰动工况也这么小。本轮Q_c到达壁面—He-Xe界面，尚未将He-Xe自身储热和边界焓差纳入这份分解，不宣称整台IHX或整机能量审计完成。
