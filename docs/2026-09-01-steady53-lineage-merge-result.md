## 5. 失败路径的功率分解与方程定位

本节是在不重新仿真、不修改模型的条件下，对同一份
`run/raw_result.mat` 做的只读复算。物性计算固定调用冻结 runtime 的
`HeXe_property_simulink.m`，没有调用根目录下可能被路径遮蔽的同名函数。

### 5.1 压气机功率反向峰值由入口温度路径主导

✅ 活动压气机功率可由原始信号重建为

```text
Wc = mdot * cp(Tin, Pin) * (Tout - Tin)
```

225 个保存样本上的最大相对重建误差为 `2.533e-8`。关键点为：

| 量 | 0 s | 18.048012 s（压气机峰值） | 500 s |
|---|---:|---:|---:|
| 压气机功率 / kW | 1205.853302 | 1673.096088 | 1304.885671 |
| 压气机入口温度 / K | 397.674835 | 552.342113 | 430.478843 |
| 压缩温升 / K | 193.498844 | 268.618711 | 209.427390 |
| He-Xe 流量 / kg/s | 11.982029 | 11.982029 | 11.982029 |
| 入口 `cp` / J/(kg K) | 520.098661 | 519.821508 | 520.006298 |
| 压比 | 2.362024 | 2.362024 | 2.362024 |
| 压气机查表流量比 | 0.995185 | 0.995185 | 0.995185 |
| 压气机查表转速比 | 1.000000 | 1.000000 | 1.000000 |

✅ 从 0 s 到 18.048012 s，压气机功率倍率的精确乘积分解为：

```text
1.38747896
= 1.00000002  (流量倍率)
* 0.999467115 (cp 倍率)
* 1.38821868  (温升倍率)
```

因此该候选早期压气机功率上冲不是流量、压比、查表转速或 `cp` 的变化造成；
直接作用量是入口温度抬升后产生的压缩温升扩大。

✅ 论文效率口径电功率采用 `0.98*(WT-Wc)`。0 s 至 18.048012 s：透平功率
增加 `11.548381 kW`，压气机耗功增加 `467.242786 kW`，所以电功率变化为
`0.98*(11.548381-467.242786)=-446.580516 kW`。这直接解释了候选电功率为何
与论文方向相反。

### 5.2 入口温度上冲来自不相容的热状态拼接

✅ Simulink 官方 API 追线确认：压气机入口温度等于
`precooler/precooler_2/T_h2_out_Integrator`。该状态从
`397.674835 K` 上升到 18.048012 s 的 `552.342113 K`，随后回落到 500 s 的
`430.478843 K`。

✅ 官方 API 读取的该区方程块对应：

```text
dTho/dt = [mdot*cp*(Tbar_h-Tho)
            - 0.5*h_h*A*(Tbar_h-Twall)]
           / (0.5*m_h*cp)
```

其中候选保持冻结参数 `h_h=1384.3 W/(m^2 K)`、`A=12.256 m^2`、
`m_h=0.0148 kg`。把根模型状态向量的同区三个初值
`Tbar_h=471.153329 K`、`Tho=397.674835 K`、`Twall=425.212725 K`
代入冻结方程，得到：

| 项 | 根状态向量代入冻结方程 | 冻结模型自身初值代入冻结方程 |
|---|---:|---:|
| 流动焓项 / W | 457756.493 | 393252.522 |
| 半区热侧换热项 / W | 389713.700 | 393252.007 |
| 状态方程残差 / W | **+68042.792** | **+0.516** |
| `dTho/dt` / K/s | **+17685.059** | **+0.134** |

保存轨迹第一个 `80.19 us` 区间的有限差分斜率为约 `+15386 K/s`，与上述
瞬时方程方向和量级相符。

❓ 因而本实验能否定的是“根模型 40 状态向量可直接作为冻结模型初态”这一谱系拼接
假设。压气机和电功率的反向大峰值是该不相容拼接的可追踪后果；这不是证明预冷器
参数、冻结初值或作者初值本身已经正确，也不是证明其余曲线差异只有这一个原因。

## 9. 出口初值的时间尺度与可辨识性审计

### 9.1 官方 API 纠正了 IHX 目标路径

✅ Simulink 官方 API 逐级追线得到：

```text
IHX/out3 (T_co)
  <- IHX/IHX_region_1/out5 (T_HeXe_out)
  <- IHX/IHX_region_1/T_c2_out_Integrator

precooler/out3 (T_h,o)
  <- precooler/precooler_2/out1 (T_h,o)
  <- precooler/precooler_2/T_h2_out_Integrator
```

✅ `IHX_region_2/out5` 连到 `IHX_region_1/in5`，所以第二区冷侧状态对涡轮入口存在间接
路径，但涡轮入口的直接状态是**第一区** `T_c2_out_Integrator`。先前 A3 书面
规格中仅修改第二区两个 He-Xe 状态的选择，只由“可达到透平功率”支持，不是对直接
输出状态的准确定位。

### 9.2 这些 He-Xe 流体状态在毫秒级忘记初值

✅ 官方 API 显示，IHX 冷侧平均温度/出口温度以及预冷器热侧出口温度的对流项，
均以 `0.5*m*cp` 为状态方程分母。对自身温度的直接线性系数因而为

```text
-mdot*cp / (0.5*m*cp) = -2*mdot/m
```

在其他状态短时间内视为不变时，初值差的局部遗忘时间常数为 `tau=m/(2*mdot)`。
候选的 `mdot=11.9820292904 kg/s`，API 读出 `m_HeXe_region=0.00919 kg`、
`m_h_region=0.0148 kg`：

| 路径 | `tau` | `5*tau` | 5 ms 后直接初值差剩余比例 |
|---|---:|---:|---:|
| IHX 单区 He-Xe 状态 | 0.383491 ms | 1.917455 ms | `2.176e-6` |
| 预冷器单区 He-Xe 热侧状态 | 0.617592 ms | 3.087958 ms | `3.048e-4` |

✅ 论文图 5.19 的压气机谷值约在 `30 s`，透平上升约在 `150 s` 完成；分别是上述
局部时间常数的约 `4.86e4` 倍和 `3.91e5` 倍。因此这些出口/平均流体温度的初值
本身不能作为 30–150 s 功率形状的长记忆状态；长时间形状必须由壁温、大质量冷却剂/
散热器、热源边界或它们的耦合演化驱动。

❓ 上述结论不表示流体初值绝对不会通过短时换热向壁温传递任何能量；它否定的是
“只凭两个毫秒级流体初值就能唯一识别论文 150 s 曲线”这一前提。

### 9.3 已保存原始轨迹验证了“快出口、慢热网络”

✅ 预冷器出口在 `0→4.823 ms` 由 `397.674835 K` 跳到 `405.000838 K`；但在局部初值
已基本遗忘之后，它仍在 `10 s` 和 `18.048 s` 升到 `545.220451 K` 和 `552.342113 K`。
同期慢状态为：

| 量 | 0 s | 10 s | 18.048 s |
|---|---:|---:|---:|
| 预冷器第二区壁温 / K | 425.212725 | 544.830312 | 559.593767 |
| 预冷器第二区冷侧平均温度 / K | 424.423159 | 545.061995 | 559.349625 |
| 散热器状态 / K | 590.007693 | 578.355614 | 569.896158 |
| 预冷器冷侧入口 / K | 571.694305 | 567.315627 | 536.776472 |

✅ 这说明 `18 s` 的压气机反向峰值不是 `T_h2_out` 一个初值仍在发挥作用；它是
预冷器壁体与冷却回路整体过热历史的代数跟随结果。候选的散热器初值来自根谱系
`590.007693 K`，而冻结模型自身是 `416.607967 K`，这一 `173.399725 K` 差异是已否定
跨谱系拼接中最明显的慢热状态不相容证据，但不能反称其中任意一个值就是作者初值。

✅ IHX 第一区冷侧出口在 `0→4.823 ms` 仅由 `1515.329092 K` 变到 `1516.143868 K`，
但在 `10 s` 到达 `1523.220243 K`。同期第一区壁温由 `1551.969568 K` 到
`1556.884518 K`，冷侧平均温度由 `1443.603498 K` 到 `1457.439658 K`。透平入口同样
在毫秒后跟随壁温和平均温度组合，而不是保留自己的初值。

### 9.4 只凭图 5.19 不能唯一反演作者热状态

✅ 在毫秒级快过程后，两个出口方程的准稳态关系分别为：

```text
IHX cold outlet       ≈ Tbar_c + k_c*(Twall-Tbar_c)
precooler hot outlet  ≈ Tbar_h - k_h*(Tbar_h-Twall)

k = 0.5*h*A/(mdot*cp)
```

即使 `h/A/mdot/cp` 全部固定，一条出口温度历史在每个时刻也只给出
`Tbar` 和 `Twall` 之间的一个组合约束；模型还有两个区、热/冷侧、上游边界与散热器状态。
因而图 5.19 的一条功率曲线不能唯一识别这些初值。

✅ 已有的全部十个 IHX 热状态统一设为 `1200 K` 的独立部件试验，使冷端、热端和两壁
算术平均均从约 `1200 K` 起升；但模型在 500 s 的热端/冷端/壁温为
`1452.180/1533.002/1522.450 K`，各自 1% 稳定区间约在 `16–26 s`。论文读图终值约为
`1444/1524/1491 K`，文字称 IHX 约 `50 s` 后趋稳。这证明“把更多 IHX 初值改成
1200 K”会生成升温曲线，却仍不会自动复原论文的终值和时间尺度。

❓ 对论文图 5.18(a) 平台点套用当前 `h_Li/h_HeXe=8.99966` 和论文单壁方程的既有
只读审计，给出零壁储能所需比值约 `4.82–7.20`；当前两区两壁如何对应论文单一
`T_IHX` 尚未证明，因此这是结构/参数不相容警报，不是直接授权修改 `h`。

### 9.5 对 A3 和后续主线的决定

- ❌ **不执行当前 A3 单次仿真。**它的两个目标是 IHX 第二区毫秒级流体状态，不是
  涡轮入口的直接状态；运行后即使功率变化，也无法唯一归因到论文的 150 s 慢过程。
- ✅ 下一个有效的证伪对象应改为**慢热状态族**：IHX 壁温/热侧及热源边界，以及预冷器
  壁温/冷侧/散热器。候选必须同时满足论文图 5.18 的部件方向、表 5.2 终点和局部能量余量，
  不能再只用图 5.19 功率误差选初值。
- ✅ 当前已能对外说明的近因是：**跨谱系的热状态与冻结方程/参数不相容，造成上游温度
  历史方向错误，再通过已验证的 TAC 代数功率路径产生反向功率曲线。**
- ❓ 当前还不能对外宣称的远因是“作者精确初值是什么”或“只改哪一个参数就能复原”；论文
  没有给出足够状态和运行时序，当前 IHX/散热器结构族又已有独立不相容证据。
