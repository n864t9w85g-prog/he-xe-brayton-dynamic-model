## 1. He-Xe侧：末点模型储热很小

**后续核查补充：** ✅ [全链条核查](2026-09-06-whole-chain-readonly-budget.md)发现部分早期压气机记录功率与对齐CSV行复算不相容，并确认运行器使用线性插值。❓ 本文早期He-Xe储热极值因此仅作为对齐记录重建的方程余额，不能当作独立验证的真实瞬态储热；末点复算通过，末点结论保持。

❓ [进一步流量对齐验证](2026-09-06-flow-alignment-diagnostic.md)已解释压气机记录假差；仅重建四路已核实离散流量的保持值后，本文两项早期He-Xe方程余额峰值仍位于280秒节点且数值不变。不能将它们全部归为插值伪差，亦不能升级为独立物理验证。

❓ 对每个区，使用实际物性函数值计算 `ṁcp(T_mean,P_region)ΔT`，与壁面换热相减，重建该侧模型的储热余额：

| 接口 | 壁面换热 / kW | 模型对流热量 / kW | 模型储热余额 / W |
|---|---:|---:|---:|
| IHX壁面→He-Xe | 2922.759602 | 2922.759601 | +0.001684 |
| 预冷器He-Xe→壁面 | 1882.379437 | 1882.379433 | −0.004259 |

❓ 表中正号表示该侧吸收的净储热，负号表示释放；数值来自保存状态的方程重建，不是独立量热观测。早期保存样本中，两者最大绝对余额分别约3.346 kW和2.154 kW，不能据末点结果宣称整个瞬态均无储热。

❓ **这里的He-Xe对流热量不是经过独立热力学验证的端点焓差。** 当前非理想气体物性依赖压力，跨变压路径不能简单将点比热乘温差当成真实焓差。历史日志第27节还记录过部分跨温区路径的比热奇点，本轮没有重复跨奇点积分，也没有用物性候选替代原函数。因此本轮不宣称He-Xe完整热力学一致性已经通过。

## 2. NaK接口：54.181 kW差额分解

❓ 在同一末点温度、流量下，按NaK现有多项式积分建立共同焓差参考，得到以下热量：

| 定义 | 热量 / kW |
|---|---:|
| 预冷器热侧→壁面 | 1882.379437 |
| 预冷器壁面→NaK | 1882.379437 |
| 预冷器两区平均温度比热对流项 | 1882.379437 |
| 共同NaK路径焓差 | **1883.444104** |
| 散热器入口比热对流项 | **1828.198318** |
| 散热器对外辐射 | **1828.198318** |

✅ 当前预冷器冷侧在各区平均温度取NaK比热；散热器在入口温度取比热。两者采用相同多项式但不同取值口径。散热器参数使用真实冻结运行文件：A_rad=300、A1增益10、h_h=3000、M_rad=150、Cp_rad=900；没有套用旧模型的1113/5744等参数。

❓ 以“预冷器热侧到壁面的热量−辐射热量”为总差额，分解为：

| 分项 | 末点 / W |
|---|---:|
| 预冷器壁面储热 | +0.000225 |
| 预冷器NaK模型储热 | +0.000008 |
| 预冷器对流项−共同焓差 | **−1064.667130** |
| 共同焓差−散热器对流项 | **+55245.786388** |
| 散热器壁面储热 | +0.000105 |
| 总差额 | **+54181.119591** |

❓ 两端各自在自身点比热口径下接近稳态，并不意味着整个NaK回路的热量一致。将散热器对流热量调到更接近预冷器，不能单凭接近程度判定正确；需要一致的焓差定义及相应物理依据。该问题历史冻结模型已有相关研究，本轮新增的是当前31745b64模型对应基线的时序量化，不将它包装成首次发现。

## 3. 整条诊断链现在支持什么

| 位置 | 当前证据支持的结论 |
|---|---|
| 反应堆燃料→液锂出口式 | ⚠️ 前轮已定位约81.219 kW内部差额；本轮未重算该项，仍是最早有直接证据的失配点 |
| 液锂边界→IHX | ⚠️ 前轮已分离约17.170 kW上游口径净差与约12.744 W分区比热差；本轮未重算 |
| IHX和预冷器He-Xe侧 | ❓ 本轮实际物性调用与模型对流余额检查：末点储热不足0.01 W；不等于真实焓差验证 |
| 预冷器→NaK→散热器 | ❓ 本轮分解出约54.181 kW持续差额，主要由点比热口径差解释 |

❓ IHX约2922.760 kW与预冷器约1882.379 kW之间还有透平做功、压气机耗功和回热器交换，不能直接要求这两个部件的换热功率相等，也不能将它们相减直接当成系统漏热。本轮没有补齐TAC及回热器的完整热力学收支，因此仍不宣称整机能量闭合或论文复现完成。

这些结果足以约束下一步：先处理已证实的热量接口一致性，再评价旋转机械数据缺失造成的剩余偏差；不得拿猜表、流量反推或散热面积调整来抵消这些接口差额。正式模型仍保持只读。
