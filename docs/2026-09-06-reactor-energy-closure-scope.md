## 1. 核查问题与计算边界

✅ 当前燃料方程使用κ=2.246e−5 K/J、γ=0.2906 s⁻¹，对应燃料向外传热系数H_f=γ/κ=12938.557435 W/K；出口式使用H_out=13296 W/K、cp=4111 J/(kg·K)。此前局部实验仅令H_out=H_f，详见[局部对照记录](2026-09-06-reactor-coefficient-local-check.md)。本轮重新读取该实验摘要、验证记录，并核对两个探索模型的保存哈希。

❓ 以下均为固定Tin=1426.47849575311 K、保留当前燃料及冷却剂反馈参数、外加反应性为零的**正功率平衡点离线求解**。不是论文工况参数恢复，不是14000 s整机联算，也不是新的瞬态运行。

使用的方程为：

```
Tm = (Tin + Tout)/2
0 = αf(Tf−1722) + αc(Tm−1516.1)
P = H_f(Tf−Tm)
Q_out = H_out(Tf−Tm)
```

✅ 当前αf=−1.28e−5、αc=−1.67e−5。❓ 固定比热时Q_out=ṁ×4111×(Tout−Tin)；焓差口径时Q_out=ṁ∫cp(T)dT。积分采用当前根目录ORNL相关式，所有计算的液锂温度都在453.7–1608 K范围内。保留这些参数仅为隔离当前实现问题，不表示已确认它们是作者真实输入。
