## 5. 沿真实能量链定位第一处失配

✅ 当前顶层连接为：反应堆锂出口→IHX热侧→锂回堆；IHX冷侧→透平→回热器热侧→预冷器热侧→压气机→回热器冷侧→IHX；预冷器NaK出口→散热器→预冷器NaK入口。不是一条把反应堆功率原封不动送到散热器的串联链：TAC提取净轴功，回热器内部回收热量。连接证据见只读SLX清单。

### 5.1 第一处：反应堆燃料放热与出口携热不相等

✅ 当前块和连线得到（常数均来自当前 SLX，不沿用旧数值）：

```text
kappa = 2.246e-5             gamma = 0.2906
hA1 = hA2 = 13296 W/K        cp_Li = 4111 J/(kg K)
m_Li = 4.572 kg/s

dTf/dt = kappa*P_Rx - gamma*(Tf - (Tin+Tout)/2)
Tout = Tin + 2*hA*(Tf-Tin)/(2*m_Li*cp_Li+hA)
```

✅ 论文PDF93–94/印刷78–79页，燃料能量变化等于产热减去转移给冷却剂的热量；式(5.5)–(5.7)分别规定燃料动态、锂携热及平均温度。按当前实现的量纲，燃料侧等效传热系数应是gamma/kappa，不能因论文对kappa的文字称谓就把倒数用反。

❓ 代数消元（是当前方程推导，不是论文给定的修正值）：

```text
Q_fuel = (gamma/kappa)*(Tf - Tave)
Q_out  = m_Li*cp_Li*(Tout-Tin) = hA*(Tf-Tave)
Q_out - Q_fuel = (13296 - 12938.557435)*(Tf-Tave)
```

✅ 末样本：Tin=1426.478496、Tout=1587.217148、Tf=1734.071201 K；P_Rx=2939.942744 kW。

| 末点量 | ❓ 用保存状态/当前方程复算 |
|---|---:|
| 燃料向冷却剂放热 Q_fuel | 2939.942744 kW |
| 出口按反应堆cp携热 Q_out | 3021.162051 kW |
| 两者差额 | **+81.219307 kW（Q_fuel的+2.763%）** |
| 燃料储热 (dTf/dt)/kappa | +0.000173 W |
| 末点燃料温度导数 | 3.895e-9 K/s；末两个原始时刻差商2.957e-9 K/s |

✅ 独立用出口代数式重算全部211个样本，与原始出口温度的最大差为8.87e-12 K；两个传热表达式的差额恒等式也逐样本成立。差额在瞬态中已保留储热后计算，不能归因于“末点还在蓄热”。✅ 当前路径未见承载这81.22kW差额的独立能量项。

**定位含义：** ✅ 这是沿指定链路在反应堆内部首先可直接核实的表示不一致；❓ 不足以证明它造成了全部275.94kW堆功率偏差，更不能证明把任一系数改到另一系数就能恢复作者曲线。此处不提出或实施参数修正。
