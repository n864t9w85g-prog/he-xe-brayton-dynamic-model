### D02续查：回热器方程、串联热阻与局部离散检查（2026-09-08）

```
Qh = Hh*(xh−w)
xh' = [2*Ch*(Thi−xh)−Qh]/Bh
yh' = [2*Ch*(xh−yh)−Qh]/Bh
Qc = Hc*(w−xc)
xc' = [2*Cc*(Tci−xc)+Qc]/Bc
yc' = [2*Cc*(xc−yc)+Qc]/Bc
```
