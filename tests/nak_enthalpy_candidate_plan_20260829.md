# NaK 统一焓差候选实施计划（探索区）

## 范围

- 只使用不可变稳态基线快照 `tmp/steady53_curves_20260828/source_f8bcd83/final_steady_24a.slx`。
- 只在 `tmp/` 生成候选副本；正式 SLX、正式 `.mat` 与物性函数均不可修改。
- 唯一行为变量：把散热器现有的入口定压比热近似
  `m*cp(T_in)*(T_in-T_out)` 改为同一现行 NaK `cp(T)` 多项式的解析焓差
  `m*(H(T_in)-H(T_out))`。
- 保持质量流量、几何、换热系数、辐射参数、初始值、边界、其余方程和连线不变。
- 候选只用于验证能量口径假设，不自动晋升为正式修复。

## 红—绿验证

1. **RED**：在原模型 14,000 秒原始输出上运行独立验收器；必须因散热器焓差与对流热流相差约 43 kW 而失败。
2. **GREEN**：通过 MATLAB/Simulink 官方 API 仅替换临时副本内 `rediator/Tho` 的出口温度代数求解。
3. 重新打开候选模型，核对块、参数、状态初值、求解器配置和连线差异；除单一替换块外不得改变。
4. 先跑 500 秒；若有限且完成，再跑 14,000 秒。
5. 候选 14,000 秒必须同时满足：
   - `|Q_radiator,enthalpy - Q_radiator,convection| < 1 W`；
   - `|Q_precooler,cold - Q_radiator,enthalpy| < 1 kW`；
   - 所有读取的端点有限，且仿真实际到达请求停止时刻。
6. 单独比较论文表 5.2 的 NaK、He-Xe 温度；能量闭合与论文接近度不得互相替代。
7. 再核验 34 个受保护文件哈希，并把证据写入诊断报告。

## 停止条件

- 候选出现非有限值、求解根无物理包围区间、未到停止时刻或引入额外结构差异时，保留失败证据并停止该候选。
- 即便全部探索区判据通过，也只能说明“该单变量处理修复了已定位的能量口径不一致”；不能据此宣称论文已复现或正式模型已修复。
